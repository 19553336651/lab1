# 实验室智能考勤 (Lab Attendance) 使用指南

本智能体旨在通过简便的方式，基于主机开关机时间自动记录和计算实验室考勤时长，完全免除传统的网页打卡、照片辅证等繁琐操作。

## 🌟 核心功能

1. **考勤申报与时长计算**：自动提取用户输入的开/关机时间（支持自然语言或系统日志），精准计算当日考勤时长（精确到分钟并转为小时）。
2. **数据自动持久化存储**：每次申报成功后，自动将记录写入本地文件（如 `attendance_records.csv`），确保数据永不丢失。
3. **实时考勤查询指令**：支持使用快捷命令实时查询本周已打卡的明细、累计时长及达标进度。
4. **自动生成周总结**：每周（上周五至本周五为一周期）自动汇总数据，核对是否达到 40 小时目标，并生成周报。
5. **期末学期总汇总**：一键读取历史存储数据，按周进行数据透视，输出整个学期的完整考勤报告。

---

## 🚀 操作步骤

### 1. 日常考勤申报

只需在对话框中告诉智能体你今天的主机开机和关机时间即可。

* **示例输入**：

  * 直接粘贴包含时间的系统开关机日志图片

    开关机日志：按下 **Win + R** 键打开“运行”对话框，输入 **eventvwr.msc**，然后按回车键启动事件查看器；

    ​                       在左侧导航栏依次展开“Windows 日志”，然后点击“系统”。

    ​			在右侧操作面板中点击“筛选当前日志”。

    ​			在弹出的窗口中，于“事件ID”输入框内输入 **6005,6006**。

* **系统响应**：智能体会自动计算当日有效时长，反馈给您，并自动将数据存储到虚拟机记录文件中。

### 2. 实时查询考勤进度

想要知道本周还差多少小时达标，可随时输入快捷指令。

* **输入命令**：
  * `/查看考勤` 
  * `/attendance`
* **系统响应**：智能体会列出本周的所有打卡明细、当前累计总时长，以及距离 40 小时目标的差额。

### 3. 获取周总结

每周结束时（如周五），可以要求智能体为您生成本周的考勤报表。

* **示例输入**：
  * *“帮我生成一下这周的周总结”*
  * *“本周考勤达标了吗？”*
* **系统响应**：智能体会汇总“上周五至本周五”的所有数据，输出周报表格并告知是否达标。

### 4. 学期末总汇总

在学期末需要上报总考勤时，可一键生成全学期报告。

* **示例输入**：
  * *“帮我做一下期末汇总”*
  * *“生成学期统计报告”*
* **系统响应**：智能体会读取所有历史打卡记录，按周次进行分类汇总，输出一整学期的完整考勤报告。
